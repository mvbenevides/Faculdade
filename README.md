Versões reescritas para estudo, com os mesmos temas das listas 04, 05 e 06.
Referência: https://github.com/GabrielLimaCunha/Ex-2B-1-2-3
Revisão consultada: 8188bb0.

São 25 programas independentes: 10 na lista 04, 10 na lista 05 e 5 na lista 06.
Os objetivos, quantidades e regras principais foram mantidos. Os exemplos fixos,
as mensagens e partes da implementação foram alterados. A lista 06 usa Scanner.

## Como executar

Instale um JDK 8 ou superior. Abra o terminal na pasta da lista desejada:

```sh
cd lista04
javac -encoding UTF-8 Ex03.java
java Ex03
```

Troque o nome do arquivo para executar outro exercício. Compile cada pasta
separadamente: os nomes Ex01, Ex02 etc. se repetem nas três listas.

Use ponto nos números decimais, por exemplo `7.5` ou `12.90`.
Os programas esperam o tipo de dado solicitado; letras no lugar de números
não são tratadas. Nos cálculos monetários, double é usado para praticar vetores.
